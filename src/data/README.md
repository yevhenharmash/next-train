# Station list

`stations.json` is every station the National Rail Darwin API can be queried for, as `[crs, name]` pairs sorted by name.

It comes from [davwheat/uk-railway-stations](https://github.com/davwheat/uk-railway-stations) (`stations.json`, fetched 2026-10-13), which is built on [Trainline EU's stations](https://github.com/trainline-eu/stations) and their [sources](https://github.com/trainline-eu/stations#licence). The coordinates and country are dropped, and the list is sorted.
